## 当前控制原理

默认策略改为 `control_strategy=native_support`：

```
F_support[i] = 该轴切入前最新 0x2C 的有符号实测值
F_command[i] = F_support[i]
```

不附加外部位置 PID、位置弹簧、速度阻尼或自动回中，也不把支撑力变成零。支撑参考只在本次进入时明确建立一次，人工操作过程中不追随测量漂移，不把手力误当成新的保持目标。六轴原始 g 保留正负号，通过现有集中 g/N 换算和一阶实际 dt 限速执行。真实力用于负载变化记录、绝对力保护及故障监测，不添加未经验证的正反馈助力。

原 `velocity_damping` 策略保留为显式可选项用于对比，不是默认手动方式。其公式方向在“正速度对应伸长、正力对应正向作用”的约定下是抵抗运动；D=500 N·s/m 时，2 mm/s 对应 1 N，再被原每轴 0.5 N 增量限制截断。六轴共同作用会增加人工阻力。不是 g/N 错换；原速度采用整组结束时刻的 dt，却把不同轴的采样时刻等同。现在速度与滤波均采用每轴 StatusFeedback 的接收完成时间差，拒绝重复/陈旧时间戳；限速仍用 monotonic 实际 dt。

**原生恒力不等于机械离合或已验证的可反驱模式。** 丝杠摩擦/自锁、厂家内部闭环、支撑接触和闭链几何可能仍使其难以手推。固定支撑力也不是大范围姿态变化的精确重力补偿，因此本入口只用于有独立机械支撑的小幅人工恢复。不能保证去掉软件阻尼后机构一定能轻推，也不能用外部增益扩大来掩盖这个未知项。

如果全部 Mode 3 后仍难以推动，应停止纯手推方案：采用可靠机械卸载或厂家明确支持的反驱/拖动功能；另一种可行研究路线是**操作员指定方向的小步六轴协同主动移动**，复用 FK/IK 和已有 Mode 3 外位置环，通过力目标主动克服摩擦。后者需要单独验证制动和位置跟踪，本文未启用，不能用手硬推或猜测手力正反馈替代。

## 六轴进入流程

1. 原 UART 单一所有者维护模式启动，只读读取六轴模式、力、位置、电流/故障及旧目标。要求全 Mode 0。未按键前不写入，不执行 Tare。
2. 提示 `DO NOT PUSH until ALL_MODE3_READY`。按住空格仅启动进入流程，此时不要推平台。
3. 整组读取当前候选力/位置，保留时间戳和原始有符号值，检查原限幅。此前 `0x27=-1 g` 不作为保持力。
4. 对每轴依次刷新该轴真实状态、确认仍为 Mode 0，再读该轴 `0x2C`，检查当前力范围。采用厂家 V2.0.4 印刷第 23 页方法二、此前真机验证的起始 `0x25` 同帧 `[3,0,encode_i16(F_support_i)]`。
5. 直接检查这次写应答携带的位置、实际力、电流、ADC/故障；回读该轴 `0x25==3`、`0x27==F_support_i` 后才继续。每轴之间不再插入完整六轴扫描。仍是**逐轴串行切换，非原子切换**，不保证受力变化完全消失。
6. 六轴完成后做一次完整检查，全部模式为 3、目标与实际使用的六轴支撑参考一致，原始交接位置偏差仍须不超过 2 steps。不能通过重置位置起点抹掉切换位移。通过后才设置 `manual_ready=true` 并打印 `ALL_MODE3_READY`。
7. 准备/应答/读回/最终检查失败立即终止进入；未切轴不继续切换。已尝试但丢应答的轴先读实际模式，再按既有方案选择恢复；模式写入不重试。交接故障不自动 Pause。已识别异常运动轴优先锚定，减少先恢复其它轴带来的等待；报告仍按 ID1～ID6 排列。

这些改动减少通信事务，不声称新的实机切换时间或成功率。

## 人工操作及保护

仅在 `ALL_MODE3_READY` 后，持续按空格，轻缓地调整有可靠支撑的整个动平台。观察六轴显示/记录，接近上限的 ID1、ID6 应朝内侧回收；不要分别强推单根电缸，不运行 HOME/PARK。目标不再附加阻尼力；必要支撑参考保留。无法推动就结束，不靠增大手力或放大软件力限值硬顶。

原保护保持：反馈 −5～2005 steps 原样保存、所有位置写入 0～2000；高/低端初始轴只允许朝内恢复，原 2-step 外移噪声容限保留；正常区域 200～1800；手动速度 2 mm/s、电流 200 mA、每轴绝对力 ±14.709975 N、500 g/s 限速、0.2 s 反馈间隔、松键 0.75 s、最长 120 s。任一故障/通信错误均退出正常目标发送。没有扩大阈值或新增清零。

## 退出与停止

按 F 完成、Q/Ctrl+C 终止、松键超时或触发保护，都进入原 UART 所有者的终止路径；不能仅停止发送、写零力或关闭串口。

已进入 Mode 3 的轴，读取新鲜当前位置，使用已验证的同帧 Mode 0＋当前位置锚定，回读后观察位置、电流、故障。若测量在端点容差内，例如 2005，仅退出目标选择 2000，测量仍记录 2005。这一向内最大 5 steps 的目标差可能产生小幅运动，不是“绝对无位移”。

未切换且原目标合法的 Mode 0 轴不做多余写入。仅手动入口允许修复与实际端点相符的旧越界目标：例如实际 2004/2005、旧目标 2004/2005，明确同帧锚定到 2000；实际/旧目标必须都在原反馈容差内且相差不超过 5。未知值、越出反馈容差或不匹配目标仍报错，不猜测/伪造位置。

保留既有 Pause 独立/故障接口及故障后的模式锚定流程，Pause 应答不能单独证明停止。部分进入失败仍不自动 Pause；进入后运行故障按原生命周期处理。总线失联、失去电源控制或进程被强杀，软件无法保证消除电机最后的力目标，必须使用独立硬件停止。终止报告仍分开输出 `position_hold_confirmed`、`hardware_stop_confirmed`、`independent_stop_required`；Mock 成功不能变成硬件停车证明。
