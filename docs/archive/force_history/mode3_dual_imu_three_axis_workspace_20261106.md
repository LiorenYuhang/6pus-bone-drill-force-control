## 新工作空间与保护

双 IMU 正常目标不再经过位置参考限速、正常力斜率或 SO(3) 角度缩放，也没有 20°/30° 的新增角度上限。XYZ 保持本次真实 FK 起点；三个姿态通道均闭合。保留 50 Hz、原 PI-D/LADRC、保持偏置、±4 N 增量、±2.5 N 积分、±1500 g 目标/反馈力界限、500 mA、电机故障、通信、IMU 新鲜度和 2.5 mm 跟踪保护。

先取几何正常行程与各轴实际设备行程的交集，再计算绝对边界。常规六轴结果：

| 边界 | steps | 用途 |
| --- | --- | --- |
| 原机械正常范围 | 200～1800 | 保留，不扩大 |
| 实际反馈故障范围 | 300～1700 | 相对机械端点预留 100 steps /2.5 mm；越过即暂停/恢复 |
| 完整 IK 目标范围 | 350～1650 | 相对实际故障边界再留 50 steps /1.25 mm，避免目标贴保护线 |

这不是“把起点 ±100 改成另一个起点小框”。边界不随初始位置移动；起点只决定补偿姿态与 IK 差分锚定。设备范围较窄时对应内缩，不能容纳余量或起点不在目标范围时明确拒绝启动。Z、单轴、六自由度组合轨迹入口不变。

停止余量参考最近真实实验：M2 故障反馈 1084 →终端锚定 1085，仅额外 1 step；从原目标边界 1083 到终端共 2 steps。故障至六轴暂停 ACK 为 17.255 ms，原运行循环间隔最大约 63.141 ms。100-step 机械预留明显大于这些已观测位移，用于新大幅工况留裕量；**未测得未来不同载荷/速度下最坏停止距离，不能把 2.5 mm 宣称为已验证的停止距离上界。** 电流、通信和跟踪异常仍立即退出，位置故障不运行偏置恢复斜坡。

每个目标先做完整 IK。可达时 `rotation_scale=1`，直接进入原 PI-D；不可达时记录 `target_reachable=false`、`ik_saturated=true`、原始目标、六轴请求及负的剩余空间，抛出 `IK_TARGET_WORKSPACE_BOUND` 或 `IK_TARGET_KINEMATIC_UNREACHABLE`，**不发送该目标的力指令，不生成缩小后的替代目标**。实际反馈另用 `ACTUAL_POSITION_WORKSPACE_BOUND` / `ACTUAL_POSITION_MECHANICAL_BOUND`，不再混淆。

5000 g/s 仅保留在原异常退出/安全恢复策略中，正常 PI-D 指令反向也不整形；硬位置/电流/通信故障直接 Pause → Mode 0，零重试。
