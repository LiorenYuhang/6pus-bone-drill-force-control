# 双 IMU 原生 Mode 3：位置 PI-D 动态响应优化

本轮只做软件修改、构建、Mock 测试与历史回放，`hardware_write_count=0`。Position/Torque、历史真机数据、底层通信协议、SO(3)/LADRC 和 IK 几何均未修改。目标仍为 Roll/Pitch/Yaw 同时参与的大幅扰动，没有恢复位置参考限速、总力滤波、正常力变化率限制或角度缩放。

## 实际修改

源文件位于 `bone_ws/src/pus6_force_control/pus6_force_control/`：

- `joint_position_force_pid.py`：增加双 IMU 可选的连续速度估计、反馈低通及运动中条件积分，补充原始/滤波速度、P/D 抵消、各轴削顶和积分阻塞诊断。默认保留原行为。
- `mode3_dual_imu.py`：双 IMU 专用 PI-D 参数覆盖；采用共享电流/正常行程基线，删除额外的内部位置框。
- `z_position_motion.py`：通过计划对象应用可选 PID 覆盖；复用电流配置校验，原 Z/单轴/组合默认仍为 500 mA，不修改其控制输出行为。
- `dual_imu_replay.py`：对同一历史输入并排计算原 PI-D 和新 PI-D；有故障快照时检查未进入 tracking 的 `pid_update` 故障帧，不再只回放最后一个完整周期。

新增 `test/test_dual_imu_pid_dynamics.py`，更新相关双 IMU 测试、当前操作文档。参数 YAML、保持力处理、力驱动和恢复协议未修改。

## 控制变化及参数

| 项目 | 原双 IMU | 当前双 IMU |
| --- | --- | --- |
| Kp | 8000 N/m | 不变 |
| Ki | 6000 N/(m·s) | 不变 |
| Kd | 5000 N·s/m | **1000 N·s/m**，六轴相同 |
| 速度回归窗口 | 80 ms | 不变 |
| 小位移速度处理 | 窗口跨度 ≤0.0375 mm 时强制速度为 0 | 使用真实量化位置回归，不再按跨度切断速度 |
| 最新反馈路径速度滤波 | 回归后直接使用，40 ms 参数未生效 | 启用 **τ=40 ms** 一阶滤波 |
| 积分 | 检测到非零速度即冻结 | 运动中也执行条件积分和实际输出防饱和反馈 |
| PID 增量限幅 | ±4 N | 不变 |
| 积分限幅 | ±2.5 N | 不变 |
| 总目标力限制 | ±1500 g | 不变 |
| 实际参考跟踪保护 | ±2.5 mm | 不变 |

连续速度滤波按每根执行器的实际 RX 时间推进，系数为 `1-exp(-axis_dt/tau)`。重复来源时间戳不推进滤波，时间回退、位置源陈旧等检查保留。进入静止后，估计速度平滑衰减，不再从窗口内运动状态直接切为零。D 始终只使用实际位置反馈速度，不对目标微分，因此没有 IK 参考跳变的 D kick；同一滤波速度供原位置预测使用。它不是总力指令的斜率整形，P 对新目标仍可立即响应。

降低 Kd 的依据是本次记录中 D 峰值达 29.18 N，而可用 PID 增量只有 ±4 N。以忽略载荷、积分和预测项的 P/D 平衡作尺度解释，原 `Kd/Kp=0.625 s`，4 mm/s 运动对应约 2.5 mm 位置偏差；新比值为 0.125 s，对应约 0.5 mm。该计算不是动力学模型或硬件性能保证；新 Kd 是有依据的下一次实验初值。

不增加 D 优先、P 优先等新分配器，也不扩大 ±4 N。条件积分只阻止把已饱和输出继续推向外侧的积分，允许有助于退出饱和的积分变化；下游实际发送力饱和时保留原积分回滚和 g 量化容差。这样避免连续速度始终非零时，原“运动即冻结积分”使负载修正和积分解卷绕无法工作。

Z、单轴、组合轨迹入口仍使用旧估计方式、Kd=5000、运动中冻结积分和原参考限速；新算法通过双 IMU 计划显式启用。

## 保护统一基线

直接核对 Position/Torque 的 `pus6_motor_driver/safety.py` 和 `pus6_kinematics/config/6pus_geometry.yaml`：两者共享 `MAX_CURRENT_MA=1500`，绝对 raw 为 0–2000，正常运动为 200–1800 steps。

双 IMU 入口本轮对齐为 **1500 mA**，不再另叠加 500 mA。目标和实际反馈使用同一正常机械/设备行程交集，典型为 **200–1800 steps**；删除此前额外设置的 300–1700 实际内框、350–1650 目标内框及其 100/50-step 预留。目标 IK 合法性与实际反馈越界仍分开记录；不可达目标明确拒绝，实际反馈越界仍立即故障恢复。原先已经存在于共享几何中的正常范围没有扩大到绝对 raw 端点，也没有增加新的角度/速度边界。

保留：实际位置反馈、2.5 mm 跟踪检查、设备行程、故障码、通信、Mode 3、0x27 读回、IMU 新鲜度、力上下限、零重试写和原 Pause/Mode 0 恢复。5000 g/s 仅保留在既有异常偏置恢复路径；紧急故障仍跳过该斜坡。电流/边界对齐不是用来改善本次回放指标：历史数据电流最高 121 mA、位置远离端点，均未触及旧保护。
