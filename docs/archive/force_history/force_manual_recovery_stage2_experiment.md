# Force Stage 2：V2 六轴 Mode 3 手动恢复真实实验

## 结果

2026-11-05 本轮实际使用 `/dev/ttyUSB0`，现有 V2 `native_support` 代码和配置，独占 UART 所有者。六轴成功进入 Mode 3，逐轴目标力读回与各自临切换前的实时 `0x2C` 保持力完全一致，程序真实打印 `ALL_MODE3_READY`。操作员反馈：**“已经推动，但仍明显推不动”**。

随后程序因 `manual motion speed protection` 自动终止，不是人工按 F 正常完成。未完成六轴居中恢复，不进行再次尝试，不增加力目标、不修改保护参数。软件退出已确认：六轴均回到 Mode 0，位置锚定读回正确，三次终止观察中的各轴电流为 0 mA、故障码为 0，位置变化不超过 1 step。串口所有者已正常退出并释放端口。

## 进入及人工阶段

- 逐轴临切换前读实际力，原生同帧 `0x25:[3,0,F_hold]`，模式和目标逐轴读回确认。
- 相邻模式写入间隔为 `25.160、24.619、25.039、23.330、19.172 ms`。比上一轮108～114 ms短，但依然是串行非原子切换。
- 第一轴模式写入至整组六轴READY检查完成约0.216秒。
- READY后至保护检查结束约 **0.353秒**，仅发送两组六轴保持命令；记录的两组控制周期间隔为132.071 ms，样本太少，不能宣称稳定控制频率。
- 两组力命令都严格等于 `[-526,155,-233,-912,599,-502] g`；外部增量力均为零，没有外部位置刚度或速度阻尼参与。
- 最后两个快照中，ID1从1956变到1968 steps，按该轴实际状态接收间隔估计速度约 **+2.268 mm/s**，超过原2 mm/s保护。此时ID1也已朝高端方向移动，后续外移判据尚未执行，速度判据先抛出异常。
- 最后Mode 3快照的ID1实际力−840 g、保持目标−526 g；ID4为−1151/−912 g；ID5为940/599 g。对应ID1/ID4伸长、ID5收缩，与原生闭环对固定力偏差作出动作的解释相容，但不足以唯一判定外力来源或机械根因。

## 保护及退出

本轮 **30次真实硬件写入**：

| 类型 | 次数 |
|---|---:|
| 同帧Mode 3＋保持力 | 6 |
| 0x27恒定保持力（两组六轴） | 12 |
| 故障路径0x1A Pause | 6 |
| 同帧Mode 0＋当前位置锚定 | 6 |
| Tare | 0 |

Pause来自现有进入后的运行故障生命周期，不是部分切换失败路径，不是本轮额外新增操作。所有Pause收到应答，但应答不等于瞬间停止：ID1在Pause应答中为1984 steps、104 mA，随后当前位置锚定到1985才完成位置保持。最后Mode 3快照中该轴为1968 steps，说明快照/判断/顺序停止之间仍有运动，不能把保护触发时的位置当作最终停车位置。

终止结果：`hardware_stop_confirmed=true`、`position_hold_confirmed=true`、`independent_stop_required=false`。这是终止观察窗口内的真实反馈确认，不是对未来失联或进程崩溃的停止能力担保。

六轴最终模式 `[0,0,0,0,0,0]`；最终实测位置 `[1985,350,121,254,912,2001]`；最终位置目标 `[1985,350,121,254,912,2000]`；电流和故障码均为0。ID5三次终止位置为913、913、912，其余各轴三次观察值不变。

## 通信

原始TX与解析完整RX逐事务配对：**366个请求、366个匹配应答**，没有未匹配请求/帧，也没有记录到通信超时。主机TX开始至完整RX帧的事务延迟为 **2.004～5.728 ms，均值3.069 ms**。这是主机观测延迟，不是设备采样时刻或命令接受/执行时间。

状态/写应答记录的各轴峰值电流依次为 `[104,0,0,43,95,0] mA`，未达到200 mA限值，所有状态/写应答故障码为0。未扩大任何限值、未修改控制算法、未修改Position/Torque、未提交/推送Git。

## 人工阻力与下一步

明确结论：**六轴Mode 3及恒定实测力的执行链通过，但手动柔顺恢复没有通过。** 本轮已经排除了“ID6仍为位置模式”和“额外外部速度阻尼”这两项作为本轮推不动的原因。模式/目标确认之后仍有明显人工阻力和向边界运动；固定力参考没有使机构成为可人工自由拖动的机构。

尚未确定：丝杠静摩擦/自锁、厂家内部力控增益/死区、支撑接触、闭链几何及六轴载荷耦合分别贡献多少。只有内部轴向传感器，没有独立人工外力测量，且人工窗口仅0.353秒，不能据此宣布某一个物理根因已证实。

下一步不建议继续增加恒力或放大保护阈值。建议开发**操作员指定方向的低速六轴协同主动恢复**：人工方向输入 → 当前FK与小步平台参考 → 现有IK生成协同轴位置参考 → 原生Mode 3外部位置/速度闭环 → 有界增量力＋支撑力。正常运动仍只用0x27，不使用普通位置模式替代；先解决既有Mode 3位置环的制动、反向和停止，再验证小范围协同恢复。没有外部手力依据时，不直接把内置力偏差当作手力正反馈助力。若必须实现真正手推，则需要厂家支持的反驱/拖动功能、机械卸载，或独立手力感知及经过验证的主动助力方案。

本轮仅提出下一阶段开发方向，没有自动执行协同回中、HOME或PARK。
