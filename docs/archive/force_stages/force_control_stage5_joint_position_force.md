# Stage 5：Mode 3 下的六轴位置反馈执行层

2026-11-04。只修改 Force；Position、Torque 只读。未提交、未推送；未执行 Tare、Pause 或 Mode 0 写入。

**结论：代码链已接通，真实静态保持通过；第一次小位移位置跟踪未通过。尚未实现三轴主动稳定，未开展基座手动扰动。** 用户随后确认机构已静止，真实只读复核确认六轴仍为 Mode 3、电流 0 mA、故障码 0。不能把该最终静止状态解释为位置跟踪成功。

## 1. 新执行链和实际复用

```text
Base IMU 相对姿态前馈 + Platform IMU SO(3) 残差 PID
  -> Position M2 已有姿态目标 R_command
  -> 原有 IK，保持捕获时的平移参考
  -> q_target = q_capture + IK(pose_target) - IK(pose_capture)
  -> Torque 一阶位置参考限速（实际 monotonic dt，0.017 m/s）
  -> 六轴位置 PI-D / PD，输出 delta_force_n
  -> F_hold_n + delta_force_n
  -> 原有每轴绝对 N 限幅
  -> force_units.py：N -> 厂家原始 g
  -> Torque 一阶力目标限速（本轮 500 g/s）
  -> 有符号 int16 / 原生 0x27 / Mode 3
```

Position 复用的是已验证的四元数相对姿态、IMU 到机械坐标变换、Base 反向前馈、Platform SO(3) 误差、M2 残差 PID 及 IK，不复用其原生位置模式和三阶指令整形执行链。原先 Stage 4 的任务空间力矩执行后端保留，Stage 5 通过 `execution_backend=joint_position_force` 明确选择新后端。

实际位置、原始力来自同一 StatusFeedback，沿用逐轴 RX 完成时间、唯一反馈序列和 Fixed-Lag 对齐。FK、双 IMU、位置 PID 和重建广义力使用相同参考时刻。FK 求解失败、反馈失效、IMU 失效和重复反馈检查沿用原机制。

真实力反馈用于原生电机内环、逐轴实际响应及 `J.T @ (F_measured - F_hold)` 监测；本阶段外部执行器位置 PID 不再先请求纯任务力矩再反解分配。它已经产生六轴力增量，不再对这个增量施加第二次逆雅可比分配。现有 Jacobian/分配器继续负责广义力监测及原任务空间后端，数学定义和符号不变。

## 2. 外部位置 PID

每轴 SI 计算：

```text
e = q_reference - q_measured                         # m
P = Kp * deadband(e)                                # N
I_candidate = clip(I + Ki * deadband(e) * dt, ±Imax) # N
D = -Kd * low_pass(dq_measured/dt)                   # N
DeltaF = clip(P + I + D, ±DeltaFmax)                 # N
```

微分作用于实测位置，避免目标阶跃微分冲击；积分受自身输出、绝对力限幅和下游限速约束，并容许原生 g 量化误差。禁用、故障、显式重新捕获位置参考时清理外部积分。F_hold 不因这些操作改变，不重复软件清零或硬件 Tare。

首轮实际测试参数：Kp=20000 N/m、Ki=10000 N/(m·s)、Kd=1000 N·s/m，D 滤波 0.04 s，积分限幅 ±1 N，增量力限幅 ±2 N。初始误差约 2 steps 即可形成约 1 N 的 P 输出。这些是本阶段新执行器外环参数，不是已经获得真机整定结果的参数。

每轴绝对力仍为 ±14.709975 N，包含 F_hold；没有修改厂家保护寄存器。原始 g 与 N 仅在已有单位边界转换，不把 Tare 后的读数当作绝对机械卸载证明。

## 3. 行程限制的实际含义

Position 原正常运动边界为 raw 200～1800 steps；本次读得六轴设备上/下限为 2000/0，实际软件执行取二者交集 200～1800，即原 HOME 映射下 0.030～0.070 m。节点另外将用户位置参数与已有几何正常边界取交集，不能通过改参数越过它。未改写设备上/下限。

Stage 4 真实起始位姿附近的已有 IK 计算显示：Roll/Pitch 10° 分别需约 167/193 steps，20° 约 330/386 steps；Yaw 10°/20° 约 32/80 steps。因此“始终不离开起点 6 steps”与正常姿态补偿目标矛盾，**6 steps 不是机械全行程**。这些 IK 数值是离线几何需求，不是硬件性能。

首次静态及 ±2-step 实验仍保留起点 ±6-step 保护，以便在小范围检查新执行链。后续软件配置明确区分：

- 机械正常绝对边界：200～1800，结合设备实际寄存器限值。
- 目标位置：IK 后必须处于正常边界。
- 参考速度：原一阶 0.017 m/s。
- 参考跟踪误差：独立配置，不能拿起点位移代替。
- 短实验起点位移窗口：可单独启用，不能被描述成真实机械制动距离。

新候选 YAML 将起点窗口设为 0（只关闭这项试验窗口），保留正常绝对边界、1 mm 参考跟踪误差、力和电流保护。**这些候选设置尚未发送到真机，不代表允许出现 1 mm 误差就是控制性能通过，更不代表故障制动已经验证。**

## 5. 根因、贡献因素与未知项

### 已有直接数据支持

1. **新增位置反馈确实产生了机械响应，但首轮参数与带限速的实际执行环不匹配。** ID1 从不动进入运动，外部 PID 在过目标后请求制动；目标力下降速度不足，实际下发指令仍为正增量。不能将这个失败解释为“Mode 3 根本不能动”或“Position 姿态算法没运行”。
2. **起点 6-step 保护中断了纠偏。** 它保护了短试验不继续下发正常命令，但不是物理停车指令。随后 PID 不再运行，无法继续反向修正。不能把触发记录当成六轴已经停止。
3. **运动中的实测力匹配不能替代位置闭环停车。** 目标匹配后仍然实际运动、电流非零。这是本次直接反例。此前只有静态匹配成功，直接将其推广为运动终止方法是不充分的。
4. **通信、编码和源数据没有发现丢失。** 2088 条常规力帧（静态 876 + 位置试验 1212）与命令上下文逐项一致，最大编码差 0 g；12 条终端保持和 12 条 Mode 3 交接另外保存。原始反馈不是命令值或 Mock。

### 有依据但不能写成确定物理根因

- 原生力环的积分/迟滞、静摩擦突破后的运动、负载重分配和机构惯性可能共同产生延迟和继续运动；没有厂家内部状态，不能宣布其中某一个已经被证明。
- Fixed-Lag 30 ms、差分速度滤波 40 ms、一周期计算/发送顺序和强制 500 g/s 斜率共同增加位置纠偏延迟。其确切闭环相位裕度尚未测得。编码器约 1-step 波动在首轮较高位置 P 和速度差分下产生明显力目标纹波；候选先降低 P、取消外部 I，保留原 D，避免单纯加大 D 放大这类量化影响。
- ID2 在没有可观测电流时位置变化约 6 steps、力读数改变，说明耦合/载荷变化需要继续观察；不能只凭这一条记录认定 ID2 方向反了。
- 这次没有做动态姿态扰动、没有外部位姿测量，不能将编码器 FK 推导当作三轴稳定性能证明。

## 6. 根据本轮结果完成的软件修正

- 引入六轴外部位置 PID 执行后端及明确 SI 参数，保留原 Stage 4 后端。
- 复用同帧 Mode 3 + 当前保持力交接，支持启动时读取到六轴已经处于 Mode 3，无须先退 Mode 0。
- 新增显式 `mode3_only`：部分进入失败只查实际状态并锁存，不执行旧 Mode 0 回退、不自动 Pause。普通旧调用的恢复行为不变。正式父节点也可将该参数传到 Child。
- Stage 5 串口记录器在写入前限制：只允许 ID1～ID6、0x27 单值或 `[Mode3,0,signed_force]` 同帧，拒绝 Mode 0、0x29、Tare、Pause 和其他参数写入。
- **本次失败后修正**：运动中或故障后不再自动发“当前实测力匹配”停车。只有已有至少 1 s、各轴位置跨度不超过 1 step 的静止观测窗口，正常结束时才允许尝试静态原生力交接，并继续观测；这仍不声称是运动制动。失败状态明确报告独立现场停止需要。
- 新候选配置将外部执行层先改为低带宽 PD：Kp=5000 N/m、Ki=0、Kd=1000 N·s/m，保留 D 滤波 0.04 s、增量 ±2 N、原绝对力限幅和原 500 g/s。名义 Kp/Kd 从 20 s⁻¹ 降至 5 s⁻¹，只是降低外环激进程度的候选，不是按模型已证明稳定的整定。这组参数**只做软件验证，未再次写硬件**。

## 8. 下一步实际实验

本轮未达到“静态及小范围执行层均通过”，因此没有要求用户进行 Base 扰动。下一步优先解决 **Mode 3 位置制动/收敛和原生内环迟滞**，不是直接加大三轴扰动或只把 6 steps 改大。

1. 在单轴小范围、其余五轴位置反馈保持下，验证降低外环带宽后的正向响应、返回、负向响应、返回，重点记录实际发送力反向时刻、原生电流消退及停车距离。先使用足够表达运动/制动的试验窗口，仍在原机械正常边界内，保留现有力/电流限制和可立即操作的独立停止。
2. 结束时先维持外部位置反馈闭环，把位置参考冻结在当前安全位置并观察收敛；不能一发现运动就关闭外环并宣称“保持力停车”。正常受控终止机制尚需实际验证，故障/断联情况下仍需独立硬件停止。
3. 若保持 500 g/s 时请求制动与实际指令长期反号，依据真实制动距离调整外环带宽与力斜率的配合，不同时任意提高 P、I 和限速。不要无依据访问厂家内部增益寄存器。
4. 六轴分别正反向位置响应、协同返回均正常后，再启用 Position M2+IK 的小姿态跟踪；确认执行层能形成协同运动，最后才通知用户进行三轴 Base 动态扰动。
