## 1. 本轮确定发现

1. 改进后的执行器位置外环确实能通过 Mode 3 产生正反向位置响应：ID1～ID3 各完成四个工况，ID4 完成正向和第一次返回。不是“发了指令但电机完全不能动”。
2. **原正常结束/故障退出处理存在实质缺陷**：关闭位置闭环后，电机仍处于 Mode 3，并继续保留最后的 0x27。停止程序、停止 UART 写入、短时静止、0 mA 均不等于撤销这个原生力目标。
3. 后续只读记录出现显著位置变化和越界/无效位置，证实这种退出方式不足以保证位置保持。没有连续记录退出后的全部运动，不能确定每轴何时开始移动、是否受额外外力影响，也不能推断发生了机械损伤。
4. 六轴完整正反向验证及协同运动 **均未完成**。ID5/ID6 的偶发耦合修正不能冒充主动阶跃测试。

## 2. 算法及执行链修正

保留 Position 的 Base IMU 反向前馈、Platform SO(3) 残差 PID、坐标定义与差分 IK；保留 Torque 的实际 monotonic dt 一阶限速公式。未修改 Position/Torque，也未使用电机位置模式、0x29、Tare 或 Pause。

```text
姿态目标/试验六轴目标
 -> 六轴目标位置（原 HOME 映射）
 -> Torque 一阶位置参考限速
 -> 最新逐轴位置/源时间戳 -> 速度估计、短时预测、位置 PI-D
 -> F_hold + DeltaF（N）

 -> force_units.py N->g
 -> 正常增力/减力制动分开的实际 dt 一阶限速
 -> 有符号 0x27，六轴 Mode 3
```

### 2.1 位置与速度反馈

- 执行器位置 PID 改用最新同轴真实 StatusFeedback 位置和逐轴 RX 完成时间，不再对已经 Fixed-Lag 的位置求差分来制动。
- 速度由约 80 ms 的实测位置历史作线性拟合；历史跨度不超过 1.5 个编码器 step 时视为无法区分的量化波动，速度估计为 0。这是估计器分辨能力，不是“电机物理速度严格为零”。不再叠加原 40 ms 微分低通延迟。
- 预测位置使用实际反馈年龄、20 ms 计算/发送预算及清除当前已下发力增量所需的限速时间。它是短时外推，不是质量、惯量或停车距离模型；相应数值均进入诊断。
- 修复一整 step 的 SI 浮点误差落在死区之外、导致 P/I 继续增加的问题（死区比较增加数值容差）。

首轮 PD 正向残差约 3 steps；小积分限幅 0.5 N 时仍有 4～5 steps 残差。后续依据真实响应采用：

|---|---:|

| Kd | 5000 N·s/m |
| 积分上限 | 每轴 ±2.5 N |

积分仅在估计静止时积累，运动时保留已学到的承载补偿而不继续增加；D 负责制动。控制请求、实际限速/编码输出用于抗饱和。受控停止时冻结位置参考，保留速度历史与承载积分，不把 F_hold 或实际目标统一清成零。

正常限速和制动限速均使用原一阶公式，没有绕过绝对力限幅。5000 g/s 是本轮新增、明确配置的制动参数，不是把 500 g/s 的结果重命名。经真实数据统计，部分工况仍有约 20～60 ms 的“请求增量已反向、编码增量仍同向”窗口，**未做到所有周期立即反向**。

每个驱动边界仍使用集中式 g/N 换算，保留正负号。若以后使用独立 IPC 驱动入口，Child 的最终速率保护上限必须允许已规划的制动斜率，否则第二次 500 g/s 限速会重新产生滞后；本轮真实 maintenance owner 直接发送正式节点已生成的目标，未再叠加第二级慢速限速。

### 2.3 FK、力重建、IMU与执行层解耦

- q/f 的任务空间重建仍使用原 Fixed-Lag，采用反馈批次时间作为新执行后端的查询基准；不把异步 q/f 当成同一物理时刻重建广义力。
- 执行层测试增加 `joint_execution_only`，只使用真实位置/力反馈，不伪造 IMU。它不是三轴主动稳定实验。
- 最新版本在同步/FK监测不可用时停止发布该周期的广义力监测，而位置闭环继续处理经过有效性、时间戳、故障和边界检查的最新真实六轴反馈。缺失的姿态/广义力标记为不可用，不补零、不冒充当前测量。
- 真正主动稳定模式下，IMU 或高层目标计算失效时冻结最后有效位置参考，继续执行器位置保持；需要显式重新使能才能恢复姿态目标更新。
- 真实电机故障、最新反馈失效/超时、机械正常边界等检查仍有效。这些硬故障下 **软件不能保证物理停车**，需要独立硬件停止。

后两项解耦修正经过软件测试，最后一次真机启动已因实际位置异常在写入前中止，因此未完成其后续硬件验证。

## 5. 最新代码采取的停止原则

- 正常停止冻结位置参考，持续真实位置反馈的制动/保持，而不是关闭闭环、写六轴零力或匹配一次实测力。
- 新 V2 实验默认在结果完成后 **保持外部位置伺服运行**。不允许以 `hold_after_experiment=false` 把带电 Mode 3 正常停止误实现成退出进程；真正关闭控制前需要独立物理停机。
- 可恢复的高层 IMU、对齐、FK/目标计算问题只冻结目标，不拆掉执行器位置环。
- 硬故障、失联或程序崩溃仍必须依赖独立的真实停机途径；发出“停止命令流”不再称为硬件已停止，结果明确记录 `hardware_stop_confirmed=false`。
- 旧 `software_force_stop()` 接口的说明已修正：它只是零力目标操作，不是运动制动/位置保持，返回值不声称停止成功。新位置停止路径不使用它。

上述新正常停止策略及进一步解耦修正只有软件验证。**本次并没有运行一个持续位置保持的最终真机进程；所有实验进程已退出，不能称为当前外部 PID 仍在保护机构。** 现场动力断电状态需要用户确认。
