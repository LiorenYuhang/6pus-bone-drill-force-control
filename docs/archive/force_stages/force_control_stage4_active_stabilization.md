### 行程保护与退出额外位移

停止前最后一批实际位置为 `[999,1006,1008,1006,999,997] steps`，ID4 相对起点 +7 steps=0.175 mm，超过原 6 steps 阈值，立即停止后续正常力命令。**保护没有被扩大，但反馈检测并不能保证物理位移恰好停在 6 steps。**

Mode 0 逐轴同帧重锚不是硬件原子停止。相对最后反馈记录，六轴 Mode 0 写入分别在约 `[8.78,26.73,45.82,63.48,82.65,103.96] ms` 后发生。ID4 到其退出前当前位置读取时已到 1012 steps，即 +13 steps；紧随退出的最终读数为 1013 steps，即 +14 steps=0.35 mm。最后多出的 1 step 尚不能独立归因于模式切换本身。已记录的约 63 ms 窗口表明，在轮到 ID4 退出前存在继续执行原生力目标的时间。

这段额外位移必须作为下一步处理事项，不能把“六轴 Mode 0 读回成功”表述为“完全无额外运动”。本轮没有修改既有退出协议，也没有自动 Pause。

## 已确认问题、未知项与下一步

**已确认：** 当前 6-step 行程保护与 10°～20°完整补偿范围明显冲突。按本轮实际起始位姿、同一几何模型，仅作离线 IK 比较：补偿 10° Roll/Pitch/Yaw 分别约需最大 `166.7/193.2/32.1 steps`，20°约需 `330.4/385.5/79.8 steps`。这些是假想姿态所需行程，不是真实运动结果；没有发送这些位置目标。本轮保留原保护后不能完整完成所需工况。

**已确认：** 控制链实际执行到 Mode 3 电机，保持力没有被零覆盖，通信应答完整；问题不是 PID 从未运行。当前示例位姿→力 PID 没有让平台建立足够的反向姿态补偿，且分配力/实测力存在偏差。

**贡献因素但非独立物理根因：** 新的力输出 P 增益、原生力环的负载响应及实际支撑/摩擦与 Position 的位置闭环不同；复制 Position 的姿态 PID不能自动复制其执行带宽。现有数据不能区分增益不足、原生力环精度/动态、载荷耦合或摩擦等贡献，不能据此擅自翻转传感器符号或宣布电机损坏。

**下一步优先顺序：**

1. 处理已经实测到的故障停止至逐轴重锚期间额外位移，明确持续 Mode 3 下的停止/退出行为；不能靠扩大阈值掩盖。
2. 在实际支撑条件下，用小幅受控动作确认分配力矩能否建立，以及 ID2/ID4 目标与真实反馈的关系，再整定位姿→力 PID 的 SI 增益。保留原 Position 姿态算法，不盲目调高外层角度增益。
3. 若仍要求三轴各 10°～20°，需要另行明确与该行程相符的安全运动范围；本轮未擅自扩大保护，也不能在 6-step 限制下承诺该效果。

目前不宜直接继续同参数 10°～20°连续扰动；本轮已经结束，不追加硬件动作。
