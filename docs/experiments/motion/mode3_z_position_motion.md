## 本次实现

新增 `pus6_force_control/z_position_motion.py`、`bone_ws/scripts/run_mode3_z_position.py/.sh`、针对性测试；在 Force 包 `setup.py` 添加 `mode3_z_position` 入口。保留旧 Z 力实验入口及所有已有有效修改。未修改 Position/Torque、UART 基线或既有 PID 算法。

```text
当前六轴实测位置 -> FK 初始位姿
固定 X/Y/RPY + 五次多项式 Z 轨迹
 -> 当前机构模型差分 IK + 实测起始执行器位置
 -> 六轴位置 PI-D（实际逐轴位置与 RX 时间估计速度）
 -> 初始保持力 + PID 增量 -> 绝对力限幅与变化率限制
 -> 现有唯一 UART owner -> 六轴 Mode 3 / 0x27
 -> 同轴状态响应的真实位置，闭环更新
```

沿用 Position 工程的 `quintic_progress`（通过 Force 自身已有 `pus6_control` 副本复用），没有 Jacobian/Wrench 力分配、力跟踪、观测器或阻抗控制。六轴共用任务空间轨迹和阶段时间；任一轴越界或失效都停止整组实验。独立 PI-D 不代表机械解耦，当前参数不能证明耦合稳定性。

先在当前位置闭环收敛，再上升；顶部位置收敛并连续保持后返回，初始位置再次收敛并保持后才退出 Mode 3。到时但未收敛会在等待超时后报错，不能报告运动成功。停止请求/异常直接使用现有终止恢复，不在异常后自动走返回轨迹。

## IK 行程与边界

从本次离线输入 HOME `[1000]*6`，初始 Z = 132.612267962 mm，目标 Z = 142.612267962 mm。完整上升路径计算 201 个 IK 点，返回复走相同路径：

| 轴 | 起点 steps | 顶点 steps | 增量 steps | 执行器单程 |
|---|---:|---:|---:|---:|
| ID1–ID6（各轴） | 1000 | 1400 | +400 | +10.000 mm |

这个结果来自现有垂直滑块机构的 IK：固定 X/Y/RPY 时 `q_i = z + 常数_i`，因此纯 Z 位移恰好与六个滑块的增量相同；代码没有硬编码 400 steps。真实执行时重新读取当前位置、求 FK/IK，实际起点不使用离线 HOME。倾斜起姿的固定姿态 Z 平移同样由 IK 求解。

六轴完整路径和运动包络写入运行报告。包络为每轴 IK 最小/最大位置再各留 100 steps（2.5 mm），并与已有正常行程 200–1800 steps、绝对 0–2000 steps、设备 `0x24/0x23` 实际边界取交集。HOME 示例包络为 900–1500 steps。轨迹超过机械边界时在 Mode 3 写入前拒绝，不自动扩大边界。

## 初始 PID 与限幅

沿用 Stage 5 V2 小位移研究参数和单机已记录的正目标对应 +位置方向；六轴大行程的效果尚未验证。控制器内部以 m、m/s、名义 N 运算，在驱动边界按 0.00980665 N/g 转为厂家 g，没有把 g 当作电机 N·m。

| 参数 | 每轴初值 |
|---|---:|
| Kp | 8000 N/m，约 815.773 g/mm |
| Ki | 6000 N/(m·s)，约 611.830 g/(mm·s) |
| Kd（测量速度阻尼） | 5000 N·s/m，约 509.858 g·s/mm |
| 积分贡献上限 | ±2.5 N，约 ±254.929 g |
| PID 总增量上限 | ±4 N，约 ±407.886 g |
| 绝对目标/反馈力保护 | ±1500 g（包含保持偏置） |
| 正常力变化率 / 减力、反向制动变化率 | 500 / 5000 g/s |
| 实时位置参考跟踪误差上限 | 2.5 mm（100 steps） |
| 原生模式交接位移保护 | 6 steps |
| 电流保护 | 500 mA，不提高 |
| 运动参考速度上限 | 0.2 mm/s（100 s 轨迹配套速度设置） |

使用现有 80 ms 量化感知速度估计、20 ms 预测及最长 100 ms 力斜率消除预测；仅静止估计时积累积分，运动保留已有承载积分。内部限幅和最终已编码输出共同用于抗饱和。保持力从本次受载 `0x2C` 采集，禁止隐式 Tare、六轴统一零力或沿用历史保持力。

默认每个移动段 100 s，五次曲线峰值速度 0.1875 mm/s，是原 200 s 曲线的两倍，起止速度/加速度仍为零。仅同步将规划检查和已有 PID 参考限速从 0.1 调为 0.2 mm/s，避免 100 s 轨迹被拒绝或限回旧速度；PID 增益、力/电流/机械边界及跟踪误差保护不变。仍可显式传入 `--move-seconds 200` 使用慢速轨迹。

起点需稳定 1 s；顶部和返回点需六轴误差均 ≤2 steps（保留 `1e-9 steps` 浮点舍入容差）、估计速度均 ≤0.05 mm/s、FK Z 误差 ≤0.1 mm，连续稳定 1 s 后再保持 3 s。每个保持阶段总等待上限 20 s。整轮约 209 s 加交接/收敛耗时。FK Z 是基于顺序采集编码器和现有几何的估计，没有外部 Z 测量，也不是实际绝对精度承诺。

## 数据与运行

`results/z_position_motion/<时间>/tracking.jsonl` 逐周期保存目标/实际位姿与 Z、六轴目标/实际位置、误差、速度、P/I/D 分量、PID 输出 g、最终目标 g、`0x2C`、电流、模式与故障。`pid` 和 `pid_input_rx_ns` 对应生成这次命令的反馈，外层 `actual_*`/`feedback_rx_ns` 对应该命令写入后收到的反馈。它们是主机时间，不是设备采样时间。

每 1 s 读取 `0x25/0x27` 并验证。`target_force_27_g_readback` 仅在当周期真实读取时填数，其余为 null；模式记录明确带最后读回时间。不会把旧读回复制成当前实测。`feedback.jsonl` 在保护检查之前保存反馈，包括触发故障的数值；串口原始 TX/RX 沿用现有记录。`z_position_report.json` 保存计划、参数、阶段结果与终止恢复结果。退出必须以已有 Mode 0 锚定/观察结果确认，无法确认则非零返回码并标记 `exit_unconfirmed`。
