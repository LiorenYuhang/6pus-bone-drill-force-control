## 运动过程

1. 读取实际六轴位置并做 FK；计算完整组合 IK 路径，在 Mode 3 进入前确定幅值、周期和包络。
2. 沿用已有保持力交接和 Mode 3 确认，起点连续收敛保持 1 秒。
3. 六自由度同时运动一个闭合周期；以本次只读起姿计算为 **184 秒**。
4. 返回本次实际起始位姿，按原有条件连续收敛 1 秒并保持 3 秒；然后执行原有六轴 Mode 0 恢复和确认，关闭串口。
5. 串口清理结束后自动生成汇总与曲线。不会继续运行下一次实验。

正常无额外等待时，从进入闭环到终点保持结束约 189 秒，加上启动/退出通信。起点和终点各保留原有 20 秒收敛超时；超时会终止并执行已有退出逻辑，不能承诺每次都正常完成。终点判据仍为六轴误差 ≤2 steps、速度估计 ≤0.05 mm/s、FK Z 误差 ≤0.1 mm，保留 1e-9 steps 浮点容差；**未增加姿态精度承诺**，完整六维返回误差会另行报告。

## 组合轨迹和完整 IK 校核

用本次实测起姿 `p0` 为中心，`u=t/T`，定义：

```
p(u) = p0 + A * E(u) * sin(2*pi*h*u)
A = [2 mm, 2 mm, 2 mm, 1 deg, 1 deg, 2 deg]
h = [2, 3, 1, 4, 5, 6]       # XYZ / Roll Pitch Yaw 的不同整周期频次
E(u) = quintic(min(6*u, 6*(1-u), 1))
quintic(v) = 10*v^3 - 15*v^4 + 6*v^5
```

六自由度贯穿全段同时变化，包络前后各用周期的 1/6 平滑启停，中间 2/3 达到完整正负幅值。起终点严格为本次实测起姿，速度与加速度归零。XYZ 单位为米，姿态沿用机构 ZYX Euler 弧度约定。

整条组合轨迹采用 18,001 点 IK 计算与数值速度检查，取实际起点差分 IK 保持编码器起点一致。先保留完整幅值并延长周期，使全部执行器参考速度低于已验证 Z 轨迹的峰值 **0.1875 mm/s**，数值导数另留 2% 余量。若机械/设备边界不允许，则统一乘 0.8 缩小幅值并重算；不提高任何边界或速度上限。运行前的最终方案写入 `combined_report.json`，控制台也会打印。

## 结果和自动分析

每次运行创建全新目录 `results/mode3_combined_pose/run_YYYYMMDD_HHMMSS_ffffff/`；启动时打印绝对目录，不覆盖历史数据。

- `combined_report.json`：实际起姿、最终规划参数、六轴行程与速度、PID 配置、阶段及 Mode 0 确认。
- `tracking.jsonl`：六维目标/FK 实际位姿、六轴目标与实际位置、误差、P/I/D 与限幅标志、PID 输出、0x27 目标与周期读回、0x2C 反馈力、电流、控制周期、模式、故障及反馈时间戳。
- `feedback.jsonl` 和原有串口记录：保护检查前反馈及通信记录。
- `summary.json` / `summary.md`：运动段与全程误差、Yaw 响应、PID/积分/最终力限幅统计、电流/周期/模式/故障情况、最后 Mode 3 及 Mode 0 观测的六维返回误差。
- `pose_tracking.png`、`joint_tracking.png`、`force_pid_current.png`、`error_correlations.png`：六维跟踪与误差、执行器误差、P/I/D/力/电流及残差相关性。

实际 FK 来自顺序读取的编码器，非同步外部测量。六自由度全部被主动指令驱动，残差相关性只能用于观察耦合迹象，不能单独归因物理交叉耦合。Yaw 在已有单轴实验中对编码器量化和保持收敛更敏感，需结合完整姿态误差与六轴输出一起分析。

若早期故障没有进入轨迹，仍生成标明故障和不可用指标的汇总；绘图异常单独写 `analysis_error.txt`，不会重新打开串口或重跑运动。

## 现场观察

观察六自由度是否连续平滑变化，尤其 Yaw 是否明显滞后、摆动或在转向时累积误差；同时留意连杆/电缆间隙、异常声响和终点漂移。控制台每约 5 秒显示六维目标/实际变化、最大位置误差和电流。不要将软件边界检查当作现场碰撞检查。

需要中止时 Ctrl+C 走已有 Mode 0 当前位保持退出，**不会强制返回起点**。真实故障同样停止轨迹，不自动重试运动；若无法确认退出，按现场独立停机方式处理。
