## 1. 结论与证据范围

**直接终止原因是 2 号执行器实际反馈越过本次起点附近的实验包络：1084 > 1083 steps。不是机械行程越界，也不是 IMU、通信、电流或 Mode 3 故障。**

目标约束与实际反馈保护共用同一边界，IK 将目标持续压到上边界，未给真实闭环误差、编码器量化及停止余量留下空间。2 号轴到达边界时仍保留积分输出，速度估计多次归零，随后多走 1 step（0.025 mm）即触发保护。暂停后最终锚定在 1085 steps。不能将这次故障解释为浮点误判，也不能因此扩大或删除实际位置保护。

已读取实验目录全部 17 个文件，包括完整 JSON/JSONL、两个 IMU 日志和 read-events CSV：950 次力控制周期、949 条完整 tracking、960 条 feedback、6180 条解析 RX 帧、8616 条串口 TX/RX 记录及故障快照、退出报告。最后一周期在写入并接收反馈后检查位置时失败，因此没有第 950 条 tracking/FK；其目标、PID 和新反馈保存在故障快照中。空的 child_cycles/write_metrics/warnings 不提供额外周期证据，stall summary 的零不能解释为实测无卡顿。

## 5. 贴边行为、贡献因素与未知项

**Root cause（确定的故障链）：** 大幅基座倾斜要求超出局部姿态范围 → IK 缩放目标到与实际退出保护相同的边界 → M2 实际越过上界 1 step → `ACTUAL_POSITION_ENVELOPE_BOUND`。设计上没有目标内缩余量，这是本次可直接定位的软件问题；保护按当前定义正确执行。

**Contributors（有数据支持，因果强度有边界）：**

1. 基座 Pitch 扰动达 12.293°，而该组合 Roll/Pitch 下有界 Pitch 约 4.569°，持续饱和使目标长期贴边。即使消除这次退出，也不可能在不扩大工作范围的条件下完整抵消该扰动。
2. 速度回归采用 80 ms 窗口，位置跨度不大于 0.0375 mm 时直接令速度为零（`joint_position_force_pid.py:95–103`）。M2 后段呈阶梯移动，估计在 0 与约 0.73 mm/s 间切换；这不是传感器超时，但会使 D 阻尼断续。
3. 在 M2=1083 时，P≈0、D 多次为 0，I 仍为 +1.354662 N（约 +138.137 g），叠加保持偏置 −93 g 后目标为 +45 g；短暂检测到速度时目标又变成 −327 g。故障周期仍为 +45 g。积分没有超过 ±2.5 N，但在此边界情形下没有主动卸掉；不能把“未积分饱和”等同于“没有残余推动”。记录支持其为越界贡献因素，不能单凭指令符号断言机械净加速度。
4. 最后 5 秒有 94/240 帧至少一轴 PID ±4 N 限幅。六轴 D 项峰值可达约 20.43 N，故跟踪、制动经常受输出能力约束；取消指令斜率后指令变化更直接，反馈力并未瞬时跟随。同期目标与 0x2C 最大绝对差各轴为 `[457,540,508,500,586,451]` g，不能把 0x27 ACK/读回成功等同于实际力精确跟踪。

**Symptoms：** Pitch 世界误差仍达 6.598°、LADRC/IK 饱和、局部位置滞后、非目标 Yaw 偏移，以及临界点力指令切换。它们不是 IMU 丢包或电机故障码。

**Unknown：** 无外部运动测量/机械净力模型，不能精确分离摩擦、载荷变化、机构耦合、设备内部力响应与编码器噪声对最后 1–2 steps 的贡献；也不能认定全部位移都是噪声（实测序列确实从 1078 逐步走到 1084，恢复锚定 1085）。没有故障周期 FK、没有 Python traceback、没有设备硬件时间同步证据。LADRC 的 prior input 仍是角度残差而非 IK 饱和后的实达姿态，可能影响观察器解释，但没有证据表明它产生了本次异常，不宜先重设控制器。

**最小建议（本轮不实施）：** 只修改双 IMU 的空间目标约束，将 IK 目标可行域缩到现有实际反馈包络内部，为量化和有限闭环停止误差留余量；实际包络、机械边界及其他保护全部不变。可从每侧内缩 **10 steps（0.25 mm）** 开始评估：M2 上限目标由 1083 改为 1073，而实际退出上限仍为 1083。它大于本次观察到的 1 step 触发超出及终端 2 steps 超出，但只是初始工程取值，不是已验证的停止距离保证。保持连续 SO(3) 缩放，不新增时间限速，不改 PID，不恢复正常力斜率限制。

先解决目标贴保护边界的问题；现有记录不足以要求立即修改速度估计、积分或 LADRC。它们应保留为后续实际性能问题，不能通过放宽 500 mA、跟踪误差、IMU 或机械保护来掩盖。

**是否可直接再做 60 s：不建议按原代码、原扰动幅度原样重跑。** 入口和恢复能力已能运行，但当前目标贴边问题仍会复现。完成上述局部内缩并检查边界行为后，可以继续一次小角度（例如 Roll/Pitch 各约 ±2°）、缓慢人工扰动的 60 s 实验；这属于下一次实机验证，不保证已通过。12° 级 Pitch 扰动超出本次局部补偿能力，不能以“持续 60 s”为由要求平台跟完不可达姿态。再次启动前需现场恢复所需起点；本报告仅确认实验结束时已 Mode 0，不能证明机器人现在的状态。
