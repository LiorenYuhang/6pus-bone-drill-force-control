之前解决了局部包络、正常限速/斜率、速度/D 连续性及启动积分问题，这些并不等同于完成了真实机构的动态跟踪。当前反向过程中，机构实际位置与变化中的 IK 参考分离，位置环部分轴处于输出削顶，最终由同一跟踪误差保护终止；不是“60 秒计时器不允许继续”。新算法确实执行，本次也没有初始死区内虚假积分。

**Root cause（可确定的故障链）**：基座扰动后回撤的姿态/IK 目标与实际机构反向响应不匹配 → M1 误差跨过 100 steps → PID 在发力前终止。记录能确定动态跟踪/转折超调，不能唯一识别其物理根因。

**Contributors**：位置环 ±4 N 输出限制在回撤段持续生效，目标与实际力反馈存在明显差异；大速度阶段 D 与 P 相互抵消；正积分在负向削顶时保留。后两项影响转折过程，但不能据此断言单一参数导致故障。Pitch LADRC 残差饱和只出现于终端，非保护触发源。

**Symptoms**：FK 超调、世界姿态误差增加、多轴误差同时增长、PID 削顶。不能将这些称为电机故障码或通信丢包。

**Unknown**：厂家内部力响应、摩擦/负载、六轴机械耦合各占多少，以及不同扰动下是否能持续 60 秒。两次三轴扰动输入不同，不能用退出秒数或 D 峰值变化宣称新旧算法整体性能更好/更差；缺少外部同步运动测量及动力学输入，不能把这些未知项指定为已证实的硬件能力不足。

本轮不调整控制器或保护。后续若继续优化，应优先处理记录所示的回撤/反向饱和响应及积分交接状态，核对实际力响应，而不是放宽跟踪阈值、恢复限速或反复延长相同命令。**仅简化终端不会解决动态跟踪，也不构成已具备完成 60 秒大扰动稳定的证明。**
