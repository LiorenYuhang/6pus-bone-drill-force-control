# 原生力模式：厂家规格、单位和寄存器

本页依据本地厂家资料和当前协议源码，不将未验证的固件行为写成事实。厂家力控字段统一写 **g**；SI 层使用 N，ADC 原值不做 g→N 换算。

选型表给出的 LAF50-024D 行程为 50 mm、最大推拉力 50 N、堵转/最大自锁力 80 N、力传感器量程 ±100 N、力分辨率 1 N；空载/满载速度规格为 17/8 mm/s。这些是产品表指标，不能推断本机构负载下闭环带宽或允许的六自由度扰动速度。

## 常用字段

| 地址 | 意义 | 单位/说明 |
|---|---|---|
| `0x20` | 电流保护 | mA；启动只读，不因主机目标力策略而重写 |
| `0x21` / `0x22` | 正/反向输出上限 | 手册表列 0–1000；不是 N/g 力上限 |
| `0x23` / `0x24` | 上/下行程 | 与软件几何边界共同约束可用行程 |
| `0x25` | 控制模式 | 0 Position、1 Servo、2 Speed、3 Force 等 |
| `0x27` | 原生力目标 | 有符号整数 g |
| `0x28` | 速度字段 | steps/s；不能自动解释为 Servo 轨迹有效限速 |
| `0x29` | 位置目标 | steps；当前主动 Mode 3 阶段不发送独立位置运动指令 |
| `0x2A` | 实际位置 | steps，转换使用工程 Home 偏置映射 |
| `0x2B` | 实际电流 | mA |
| `0x2C` | 实际力反馈 | 有符号 g，与目标寄存器读回分开 |
| `0x2D` | 力传感器 ADC | 原始计数 |
| `0x2F` | 故障码 | 保留原始位码，由现有驱动检查 |
| `0x1A` | Pause | ACK 是命令应答，不是独立的物理停止测量 |

Mode 3 由设备内部力闭环执行；设备内部算法与带宽没有在本工程中识别。串口六轴是顺序事务，状态帧接收时间不等于同一时刻传感器采样。

## 三种不同的边界

1. **产品最大推拉力 50 N**：规格依据，不是固件寄存器证明。
2. **主机绝对目标 ±5098 g**：±50 N 向内整数化得到，包含保持力偏置；由当前三进程软件执行。
3. **设备自身电流/输出/故障机制**：由实际设备配置和固件决定；启动保存 `0x20/0x21/0x22` 读回，但没有证明“固件自动在 50 N 钳位”。

`1 g = 0.00980665 N` 为名义换算；整数 g 指令粒度不是传感器绝对精度。电子清零、装配预载、传感器量程和正常机械力能力不可混为一谈。历史单电机反向输出读回曾存在无符号/有符号表示差异，详见[原生策略依据](../control/native_capacity.md)与[单电机实验](../experiments/native_motor/single_motor_force_control_experiment_v2.md)，不能直接替代本次六轴实测设置。
