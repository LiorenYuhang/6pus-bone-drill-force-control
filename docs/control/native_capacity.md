# 双 IMU 三进程：原生能力输出策略

2026-11-07更新，仅作用于`run_mode3_dual_imu_three_process.sh`／`--three-process`。Position、Torque及历史实验数据未修改；Z、单轴、组合及原单进程双IMU入口保留原策略。

## 厂家“50”及工程对照

- 厂家[选型手册V18.1](../../hardware/电机手册/微型伺服电缸选型手册（V18.1）(17).pdf)，印刷29页／PDF30页：LAF50-024D最大推拉力**50 N**，堵转推拉力／最大自锁力80 N、传感器范围±100 N。后两项不是正常指令能力边界。
- 厂家[力闭环电气手册V2.0.4](../../hardware/电机手册/LAF因时机器人微型伺服电缸（力闭环专用）--LA用户手册（电气）V2.0.4cn.pdf)，印刷12页／PDF14页：`0x27`力控目标单位为g；`0x20`过流保护单位为mA；`0x21/0x22`正／反向输出上限的表列范围为0–1000，不是N或g。表中没有“50 N固件自动力限幅寄存器”。主机不可据50 N产品规格假定固件自动钳位。
- 历史单电机读回曾为`0x20=1500`、`0x21=1000`、`0x22=64536`（i16为−1000）；反向符号与公开表描述不同，保留原值。这不是当前六轴设置的替代测量。
- Position J14及Torque共享驱动保留故障码、1500 mA电流、有效反馈范围与通信停止机制，没有Force的2.5 mm外层PI-D跟踪硬退出。Position发送0x29位置；Torque研究入口仍为位置驱动，其`force_limit_relative=50.98581064889641`是`relative_raw`软件范围，不是原生50 N保护。两工程的控制输入语义不能直接等同Mode 3。

Kp/Ki/Kd=8000/6000/1000、真实编码器积分死区、预测P、80 ms速度窗口、40 ms D滤波、SO(3)/LADRC全部不变。LADRC已有残差参数属于保留的姿态算法，本次没有改动。固定1秒initial_hold及原final_hold流程不变。

50 N按名义9.80665e−3 N/g转换；整数编码采用±5098 g（约49.9943 N），避免四舍五入到5099 g而越过规格边界。该g粒度不是新设低力限制。仍检查有符号i16和有限数值，避免溢出与符号翻转。实际电机内部电流／输出保护设置启动时只读并保存到`child_ready.jsonl`和报告，不写0x20/0x21/0x22，也不宣称已离线验证这些硬件保护的动作。

## 源码修改

- `joint_position_force_pid.py`：支持显式`None`取消实验限幅／跟踪退出，默认值不变；最终编码后的条件抗积分饱和仍有效。
- `mode3_process_policy.py`：三进程专用策略，集中说明厂家规格与固件保护的区别。
- `mode3_process_runtime.py`：仅三进程实例覆盖上述三项PID限幅，配置与报告保存有效策略。
- `mode3_process_child.py`：保持偏置交接及最终力使用同一50 N边界，删除1500 g反馈硬退出；保存绝对力饱和和积分回退标记。
- `dual_imu_analysis.py`：报告实际生效的跟踪阈值（None）及最终绝对力饱和次数。
- `mode3_process_replay.py`：固定历史IK／编码器输入，比较旧策略与新策略；不打开UART。
- `test_mode3_process_limits.py`及`test_mode3_three_process.py`：必要策略、整链和故障恢复测试。
