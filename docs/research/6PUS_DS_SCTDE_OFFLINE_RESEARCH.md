## 论文、变量及适配

论文研究的是 2PRU-2UPR、四驱动和 2R1T 任务空间，实验用 dSPACE 与 1 ms 采样；本工程为六驱动 6PUS，一般具有六个机构自由度。当前稳定任务选取三姿态坐标，固定平移只是研究模型假设，不等于实际 6PUS 被机械约束为三自由度。任务空间之外的平移运动、约束反力和力分配需要完整动力学建模，论文冗余结构的收敛证明不能自动推广。

论文式 (11) 为 `e=q_d-q`；此处 q 为 M1–M6 电缸滑块行程位置（m），不是论文机械结构的其他关节坐标。位置基线中 Feedback Bridge 的 `positions_meters = 0.050+(steps-1000)*0.000025`，所用期望和反馈必须处于同一原点和顺序。`TimedJointFeedback` 的每轴时间是主机接收完成时间，非设备采样时间。已实现的 ROS 研究节点接收的是带单个时间戳的合成样本，还没有将真实逐轴异步反馈、IMU、目标及加速度融合成统一状态。

论文式 (13) 将平台动力学的广义力通过 `J^+` 分配到驱动关节，再以传动比映射并加上电机侧惯性、摩擦项。代码选择局部 `η=[roll,pitch,yaw]`（rad），`R=Rz(yaw)Ry(pitch)Rx(roll)`，定义基座系固定平移的 `J=∂q/∂η`（6×3，m/rad）。任务广义力与这些欧拉坐标变化率共轭，单位 N·m；它不直接等同于任意坐标系中的物理三轴力矩向量。由虚功关系 `w=JᵀF`，采用 `F=(Jᵀ)^+w`（N）；若 `n_i=∂q_i/∂θ_i` 为有符号、理想无损传动（m/rad），任务分量的电机轴力矩为 `n_i F_i`（N·m）。真实齿轮、丝杠效率和摩擦模型及方向仍须辨识。`kinematics_map.py` 调用既有 `Analytical6PusKinematics.inverse_kinematics` 计算中心差分雅可比；该几何配置仍标记为待最终装配确认。其局部映射测试只验证数值模型，不验证机构实物。

生产前馈代码使用 Base IMU 相对姿态 `ΔR_B`，生成 `R_BP_cmd=ΔR_Bᵀ`；平台 IMU 在闭环方案中参与相对姿态反馈，再产生姿态修正和 IK 目标。本文研究实现**没有**直接连接这些生产节点：它要求调用方提供一致参考系中的 η、η_d、各自的一阶和二阶导数、q/q_d 及导数。直接欧拉角相减只在连续局部坐标有效，不能代替当前世界系 SO(3) 残差；跨 ±π、奇异角附近、基座运动、IMU 安装外参和 Euler 角速度转换均需专项处理。两路 IMU 不能自动给出已校准的世界系角加速度；位置差分速度/加速度受量化、噪声和时间对齐影响，此原型未伪称具备这些估计器。

## 控制律与离散化

论文式 (17) `Ĥ(t)=w(t−L)−M̄η̈(t−L)`；式 (18) 为 `w=M̄(η̈_d+Kp eη+Kd ėη)+Ĥ`。原论文印刷的式 (28) 任务项显示 `η̈` 与 `Kd eη`，与式 (18)、式 (19) 和量纲存在不一致。本实现明确使用式 (18) 的期望加速度与误差一阶导数，属于对原文不一致的解释，未声称与原论文作者代码完全一致。

式 (21)–(27) 的同步部分由四轴循环关系扩展为六轴相邻循环（轴 6 接轴 1）：

```
e = q_d-q; e_s[i]=e[i]-e[i+1]; c[i]=e_s[i]-e_s[i-1]
e_c=e+D∫c dt; σ=(q̇_d-q̇)+D c+P e_c
q̈_r=q̈_d+D ċ+P((q̇_d-q̇)+D c)
τ_SC = sgn(n)·(Ī_m q̈_r + Kc c + K σ) + friction_motor
τ_motor = τ_SC + n ⊙ (Jᵀ)^+ w
```

这是六轴环形图上的工程扩展；每轴顺序是电机 ID 1–6，图结构和正负号需要机械/控制研究验证。`Ī_m` 为 N·m·s²/m，`Kc` 为 N·m/m，`K` 为 N·m·s/m；它们是**电机轴力矩坐标**参数，与 PID 或轴向力参数不可混用。摩擦输入为已定义的电机轴摩擦补偿力矩 N·m。论文式 (28) 含上述同步和任务空间 TDE 两部分；这不是单纯 PID。式 (36) 是 APD 对比控制器，需要模型 `Mη,Cη,Gη,F_load` 与相应惯性/摩擦参数；这些目前没有可验证的 6PUS 数值，故未实现 APD 或将其冒充 DS-SCTDE。

离散实现使用上一有效样本的加速度和调用方提供、时间戳严格匹配上一采样的**已施加任务广义力**进行 TDE；首样本只初始化，不输出。与驱动命令不同，实际已施加力可能受饱和、摩擦、驱动内部闭环和其他轴约束影响；当前真实链没有这个量。即使有电机轴力矩，仍需在同一时刻扣除同步项及电机动力学并结合传动、雅可比建立可信估计，不能假定命令即实测。时间误差会污染估计，启动、掉帧或延迟与时序错误会锁存故障。`L` 此处是**实际相邻样本间隔**，需在配置范围内；这不是论文 1 ms 定时控制的复现。

幅值和变化率是逐轴 N·m 及 N·m/s；同步误差积分有显式数值上限，并在任一输出达到幅值或变化率限制时冻结。它们是研究防护，改变了原控制律，不继承论文收敛证明。数值异常、秩不足、迟到、外部故障和错误历史关联会锁存。故障清零和 Mock stop 是软件状态，不是设备停止。

## 文件、接口和运行

- `bone_ws/scripts/research/ds_sctde/ds_sctde.py`：独立算法，保留原 `joint_torque_pid/controller.py` 不变。
- `kinematics_map.py`：基于现有 IK 的局部姿态雅可比；`offline_compare.py`：共同合成输入比较，非动力学仿真。
- `offline_ros.py`：默认关闭的研究节点，启动时仅选 `PID_BASELINE` 或 `DS_SCTDE`，订阅私有 `~/synthetic_sample`（JSON String），发布 `~/diagnostics`（JSON String）并写入内存 `MockBackend`；没有生产话题订阅、串口或实际驱动。JSON 字段见 `test_ds_sctde.py` 的 `sample()`，应视为合成研究接口，不是生产 ROS 消息定义。状态包含算法、P/同步/TDE 中间量、力矩、饱和和错误。
- 所有 DS 参数通过 `config_json` 显式提供；默认 `enabled=false`，没有真实整定值。测试配置仅用于数学/软件验证。

隔离编译和测试：

```bash
cd /home/lyapunov/6pus_bone_drill_torque_control/bone_ws
source /opt/ros/jazzy/setup.bash
colcon --log-base /tmp/6pus-dssctde-log build --base-paths src --packages-up-to pus6_control pus6_motor_driver --build-base /tmp/6pus-dssctde-build --install-base /tmp/6pus-dssctde-install
source /tmp/6pus-dssctde-install/setup.bash
python3 -m pytest -q scripts/research/ds_sctde scripts/research/joint_torque_pid
python3 scripts/research/ds_sctde/offline_compare.py
```

该构建是继承的 ROS 包构建，研究节点是独立 Python 脚本，不被 colcon 安装。两算法可在独立 DDS 测试中使用相同合成样本，不能同时由同一节点选中；这不构成跨进程、真实电机控制权互斥。节点根据统一样本时间而不是生产逐轴时间执行检查。实际研究模式需要新的独立所有者、接口及运行状态机。

`offline_compare.py` 使用同样初始值、0.02 s 周期、同一预设误差和扰动及虚构满秩 J，分别记录输出 RMS；这仅检查两个算法对同一输入的数值响应。它不建立受力、惯量、动态、闭环跟踪模型，不代表任何控制性能排名。

本次在独立 `/tmp/6pus-dssctde-install` overlay 下，四个继承包构建完成；DS 与既有 PID 的相关测试共 35 项通过，包含独立 ROS DDS 合成输入到内存 Mock 的链路和故障路径。比较程序输出 100 个有效样本、PID 输出 RMS 约 0.000430 N·m、DS 输出 RMS 约 0.0192 N·m；这些数字只描述所选的虚构测试参数，不表示哪种控制器更好。测试配置不是机器人整定值，未开展真实动力学仿真或真机试验。

## 后续条件

要做有意义的动力学仿真，须构建或取得六轴 6PUS 的惯量、约束、传动、摩擦、外载和执行器饱和/延迟模型，给两个控制器同一物理输入输出、参数整定规则、目标和扰动并记录误差等指标。真实部署另外需要厂商正式的轴力矩指令协议和单位、真实已施加输入可观测性、同步传感器、经验证的跨进程独占及设备侧停止。首先离线验证，再经用户明确批准后才可真实使能；不得把模拟停止当成设备停止。
